\# Sistema de Controle de Acesso via QR Code



API REST desenvolvida em Python para controle de acesso de pessoas e veículos utilizando QR Code, com integração entre backend, banco de dados e hardware (Arduino).



\## Tecnologias Utilizadas

\- Python

\- Flask

\- SQLite

\- OpenCV

\- Arduino



\## Funcionalidades

\- Cadastro e autenticação de usuários

\- Geração e validação de QR Codes

\- Integração com câmera para leitura de QR Code

\- Comunicação com Arduino para controle de cancelas

\- API REST com endpoints para entrada e saída



\## Como executar o projeto

```bash

pip install -r requirements.txt

python app.py





Observações



Projeto desenvolvido para fins acadêmicos e de aprendizado em backend, APIs REST e integração de sistemas.
